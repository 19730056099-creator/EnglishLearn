# EnglishLearn

我的英语学习笔记库，用 [Obsidian](https://obsidian.md) 管理，目标是读懂计算机方向的英文资料（如 CS61B 讲义、技术博客、LangChain 文档），并逐步能用英语写作和交流。

核心思路：**英语不是由单词组成的，而是由大大小小的"块"组成的。** 所以笔记不只记单词，也记短语、搭配、句型，以及读不懂时的方法。

## 目录结构

```
EnglishLearn/
├── 单词/      # 单个词汇，侧重在 CS / 编程语境里的含义
├── 短语/      # 短语、短语动词、习语，以及它们的引申用法
├── 词块/      # 方法论：词块分类、阅读卡壳时怎么办
├── collection/  # 暂存区，还没整理的内容先放这里
└── README.md
```

| 文件夹 | 放什么 | 示例 |
|---|---|---|
| `单词/` | 单词的含义、使用场景、例子 | `compile`、`pop`、`venue` |
| `短语/` | 短语的含义和延伸 | `truck in`、`under-the-radar` |
| `词块/` | 学习方法和分类框架 | `英语词块总览`、`意群看不懂怎么办` |
| `collection/` | 待整理的素材 | |

## 从哪里开始读

- [[词块/英语词块总览]]：词块的七个概念（搭配、短语动词、习语、句子框架、套语、语域、意群）和学习优先级。
- [[词块/意群看不懂怎么办]]：读到卡住的句子时，如何判断原因，以及泛读与精读怎么配合。

## 记笔记的约定

- **一个词或短语一篇笔记**，文件名就是词或短语本身。
- 笔记里写**含义、出现场景、例句**，尽量用 CS 语境的例子。
- 单词笔记可以参考 `单词/template.md` 的写法。
- 相关的笔记之间用 `[[双向链接]]` 连起来，例如总览里的概念链接到具体的短语笔记。
- 方法类的内容放进 `词块/`，每篇只讲一个主题，用标签（如 `词块`、`方法论`、`阅读方法`）归类。
- 积累时顺手标注**口语还是正式**（语域），避免用错场合。

## 使用的工具

- **Obsidian**：笔记编辑和双向链接。
- **Obsidian Git**：自动备份到 GitHub，提交信息形如 `vault backup: 2026-10-04 18:30:19`。
- **Claudian**：在 Obsidian 内用 Claude 整理笔记、解释难句。

## 查词和查用法

- **英英词典**：Longman、Cambridge 在线版。遇到 `awkward`、`subtle` 这类和中文对不上的词，先看英英解释。
- **Ozdic**：查一个词常和哪些词搭配。
- **SkELL**：语料库，查某个说法母语者用得多不多，比如 `raise efficiency` 还是 `improve efficiency`。
